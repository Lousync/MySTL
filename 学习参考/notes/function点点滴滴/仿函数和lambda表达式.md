# 仿函数
仿函数更加准确来说应该是函数对象，一句话来说就是定义了个结构体/类然后重载了其中的opeartor()
```c++
struct TestFunctor{
    void operator()(Args...){
        //
    }

    //一些成员属性
}

//具体的调用
TestFunctor test{...};
test(args...);   //这样对象名()看起来就像一个函数调用一样
```

# 仿函数和lambda表达式
lambda表达式和仿函数其实是很有关系的，一句话来说lambda表达式就是仿函数包装的语法糖，仿函数就是lambda表达式的实际实现方法.
编译器现根据写的lambda表达式生成了一个匿名仿函数类，然后生成了一个临时对象，也就对应了上面的结构体定义，对象初始化。具体要使用表达式通常都是用auto 变量接住然后再使用

## 两者的具体关联
1. 关于外部变量的捕获
lambda表达式可以利用[]来捕获外部变量，本质就是在生成的匿名类中添加对应的成员函数；
[&]表示按引用捕获，所以匿名类中的成员属性就是引用
[=]表示按值捕获，这样在内部修改变量外面没影响
捕获可以捕获特定的变量，也可以就写&、=这样编译器会根据你operator()中用到的变量来向匿名类中添加成员变量
2. 关于operator()函数
lambda表达式中的函数参数就是生成的匿名类中的operator()函数中的参数
匿名函数中的operator()是默认最后被const修饰的不能修改按值捕获的变量，除非引用捕获，或者加上mutable来去掉const
