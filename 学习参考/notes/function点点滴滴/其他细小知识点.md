# 完美转发(c++11)
允许函数模板将参数以**原始的值类别**转发给另一个函数，从而实现零拷贝参数传递
通常使用在一个函数给另一个函数传递模板参数
## 具体实现
1. 万能引用 T&&
只有模板类型才能有万能引用哦，普通的就是右值引用
2. std::forward

# std::invoke
std::invoke(func,args...) 是一个统一的调用接口，可以处理各种可调用对象比如普通函数、lambda、仿函数、成员函数指针和数据成员指针
## 遇到成员函数时的一些使用注意
```c++
struct Calculator {
    int add(int a, int b) { return a + b; }
    int multiply(int a, int b) { return a * b; }
};

Calculator calc;

auto add_ptr = &Calculator::add;   //先取成员函数指针
std::invoke(add_ptr, calc, 3, 5);  //记得传入调用的对象
```

 # 派发标签 in_place_t/<utility>
在构造函数中加一个标签用于在构造对象的时候调用特定的构造函数,在函数重载比较多的时候可以方便构造函数匹配
这个用法的好处是不占用任何内存，不增加程序负担
```c++
class MyClass{
    MyClass(in_place_t,Args ...args){}
};

MyClass A(in_place,args);
```


# 委托构造函数
委托构造函数是 C++11 引入的特性，允许一个构造函数将初始化工作委托给另一个构造函数，避免代码重复。
## 基本语法

```cpp
class MyClass {
    int x;
    int y;
public:
    // 主构造函数（被委托者）
    MyClass(int a, int b) : x(a), y(b) {}

    // 委托构造函数（委托者）
    MyClass(int a) : MyClass(a, 0) {}  // 委托给主构造函数
    MyClass() : MyClass(0, 0) {}       // 委托给主构造函数
};
```

## 执行流程

```cpp
MyClass obj(10);

// 执行步骤：
// 1. 进入 MyClass(int a)
// 2. 委托给 MyClass(a, 0)
// 3. 主构造函数执行 x=a, y=0
// 4. 返回，完成构造
```

## 常见场景：初始化列表的重复

```cpp
// 传统写法：重复代码
class String {
    char* data;
    size_t len;
public:
    String() : data(nullptr), len(0) {}
    String(const char* s) : data(new char[strlen(s)+1]), len(strlen(s)) {
        strcpy(data, s);
    }
    String(std::nullptr_t) : data(nullptr), len(0) {}
};

// 委托构造写法：复用代码
class String {
    char* data;
    size_t len;
    void init(const char* s) { /* 通用初始化逻辑 */ }
public:
    String() : String(nullptr) {}
    String(const char* s) : data(new char[strlen(s)+1]), len(strlen(s)) {
        strcpy(data, s);
    }
    String(std::nullptr_t) : data(nullptr), len(0) {}
};
```

## 注意事项

1. **不能循环委托**
```cpp
// 错误！循环委托
MyClass(int a) : MyClass(a, 0) {}
MyClass(int a, int b) : MyClass(a) {}  // 编译错误
```

2. **虚函数的影响**
   - 在委托构造函数执行期间，对象还不是派生类对象
   - 虚函数调用会调用基类版本

3. ** initializer_list 构造函数优先**
```cpp
class MyClass {
    int x, y;
public:
    MyClass(int a, int b) : x(a), y(b) {}
    MyClass() : MyClass(0, 0) {}  // 委托
};

MyClass obj{};  // 调用 MyClass()，委托给 MyClass(0, 0)
```
