# 3+2
何为3+2？也就是创造对象的5种方法，分别是
* 默认构造函数
* 拷贝构造函数
* 复制运算符
* 移动构造函数
* 移动复制运算符
其中 前三种就算你不直接写编译器也是会帮你生成的，但是你可以显示指定默认/删除他们
默认指定 = default;
默认删除 = delete;

# 如果声明他们?
他们的函数标签都是很有讲究的
* 默认构造函数
如果不重载构造函数，就会生成没有任何参数的构造函数，其中一些成员变量会使用一些你指定的默认值
* 拷贝构造函数
用另一个相同类型的成员来构造
```c++
T(T const& _that):初始化列表{}
```
Q:为什么参数必须为引用
A:因为如果不按引用传递就会按值传递，而按值传递就会先调用拷贝构造函数生成一个副本，但是我们本身就在编写拷贝构造函数，所以就会引起循环调用
* 复制运算符
也就是 = 的重载，相当于也是一个拷贝
```c++
T& operator=(T const& _that){
    //里面的所有复制最好用深拷贝
}
```
Q:为什么返回值是引用？
A:是为了实现链式调用 也就是（a=b=c，从右到左哦）链式调用本质是 a.operator=(b.operator=(c)); 你的函数就要求传入一个左值引用，这样就能正好匹配
* 移动构造函数
就是将参数改成右值引用即可
```c++
T(T const&& _that):初始化列表{}
```
* 移动赋值运算符
```c++
T& operator=(T const&& _that){
    //注意搬空数据
}
```
Q:为什么返回值也得是引用
A:还不是为了配合链式调用，而且可以和拷贝赋值运算符混用哦，想想链式调用的本质就知道了
